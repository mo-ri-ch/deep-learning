Deep Learning, Hands-on

Deep learning right now

Chatbots, image generators, voice assistants and coding tools all run on neural networks: programs that learn from examples instead of following rules someone wrote.

New models every month

A big new model now comes out almost every month.

Models that do things

Many new models are built to use tools and write code, not only to chat. These are called agents.

Many kinds of input

One model can read text, look at images and listen to sound. This is called multimodal.

Smaller and cheaper

Small models now do jobs that needed huge ones a year ago, at a fraction of the cost.

Under all of them is one idea you'll build today: a network that learns by correcting its own mistakes.

    A neuron

    The smallest part of a network is a neuron. It takes a number in, multiplies it by a weight, adds a bias, and gives a number out:

    The rule: output = weight × input + bias
    With weight 2 and bias 1, an input of 3 gives 2 × 3 + 1 = 7.

    These dots are hours studied → test score. Move the sliders until the line passes through the dots.

    Learning means finding a weight and bias that fit the examples. You just did it by hand.

    How wrong? The loss

    A computer can't look at a picture and say "close enough". It needs one number that says how wrong the line is. That number is called the loss.

    For each dot, take the gap between the guess and the real score, and square it, so a miss below counts the same as a miss above. The loss is the average of those squares.

    The rule: loss = average of (guess − real)²

    Move the sliders and watch the loss. Can you get it to 0?

    Learning: walk downhill

    The network can't see the best line either. So it asks: "if I nudge the weight up a little, does the loss go up or down?" That direction is called the gradient.

    Then it takes a small step the other way, downhill, and asks again. This is gradient descent. How big each step is, is called the learning rate.

    The rule: new weight = weight − learning rate × gradient

    Start at weight 0, bias 0. Take steps and watch the loss fall. Then try a bigger learning rate.

    Lab 1: let PyTorch do the maths

    Real networks have millions of weights, so nobody works out gradients by hand. PyTorch, the most used deep learning library, does it for you: write the loss, call backward(), and every weight gets its gradient.

    w = torch.tensor(0.0, requires_grad=True)
loss = ((w * x + b - y) ** 2).mean()
loss.backward()
print(w.grad)   # the gradient: which way is downhill
    In Lab 1 of the notebook you'll fit the same dots, first by hand, then with PyTorch's optimizer.

    Layers, and one small bend

    One neuron can only draw a straight line. A network stacks many neurons in layers: the outputs of one layer are the inputs of the next.

    But straight lines added together are still a straight line. So after each neuron there's a tiny bend, called ReLU: keep a number if it's above 0, otherwise make it 0.

    The rule: ReLU(x) = the larger of x and 0
    ReLU(3) = 3, and ReLU(−2) = 0.

    These dots make a V. Try to fit them with and without ReLU.

    Too good to be true: overfitting

    We keep some examples aside, called the test set. The network never trains on them; they show how it does on new data.

    Train too long and it starts memorising the training examples instead of learning the pattern. Training accuracy keeps rising, but test accuracy falls. This is called overfitting.

    Drag through the training rounds. Where would you stop?

    Example numbers, drawn for this page.

    Seeing images: convolution

    For pictures, networks use a trick. A small grid of weights, called a filter, slides over the image. At each spot it multiplies each pixel by the weight on top of it and adds everything up.

    A big total means "the pattern I look for is here". This filter looks for an edge from bright to dark. A network that learns its own filters this way is a CNN (convolutional network).

    Slide the filter one step at a time and watch the edge light up.

    Don't start from zero: transfer learning

    Training a big image network from scratch takes millions of pictures. But a network already trained on millions has learned useful filters: edges, textures, shapes.

    So you keep those layers, and train only a new last layer for your own task. This is transfer learning, or fine-tuning.

    Compare two ways to learn rock, paper, scissors from the same 60 photos.

    Example numbers. You'll see your own in Lab 3.

    Models that already know a lot

    A foundation model is trained once on a huge amount of data, then used for many tasks. The chatbots you use are foundation models.

    One for images, called CLIP, learned from millions of pictures with captions. Give it a picture and a few labels, and it scores how well each label fits. No training needed. This is called zero-shot.

    Pick a picture, and see how CLIP would score the labels.
