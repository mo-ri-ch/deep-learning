# Deep Learning, Hands-on

Companion page for a 2-hour hands-on session for college students: how a neural network learns,
a CNN for rock, paper, scissors, transfer learning, a live class leaderboard, and an app to play
against your network.

**Website:** https://gradlabs.in/learn/deep-learning/ (unlisted: shared by link, kept out of search engines)

- `index.html` — home: what the session covers
- `lessons/session.html` — the session, one short page per idea, with activities
- `notebooks/deep_learning_hands_on.ipynb` — the one Colab notebook, in four labs: PyTorch basics,
  a CNN on the rock-paper-scissors photos, fine-tuning with 60 photos and the leaderboard, and a
  Gradio app; CLIP as a bonus
- `leaderboard.html` — the live class board (scores from Lab 3; the API is on gradlabs.in)
- Design: [study-notebook-design](https://github.com/mo-ri-ch/study-notebook-design), loaded live
